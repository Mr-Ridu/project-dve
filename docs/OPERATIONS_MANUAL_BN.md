# সাইট চালানোর ম্যানুয়াল (দৈনন্দিন কাজ)

এই ম্যানুয়ালটা সেই ব্যক্তির জন্য যিনি সাইটে নতুন ইউজার অনুমোদন করবেন আর টিউটোরিয়াল যোগ করবেন — coding জানার দরকার নেই।

---

## ১. তিনটি লিংক মনে রাখুন

| লিংক | কাজ |
|---|---|
| `https://example.com/dashboard/` | প্রতিদিনের কাজ: ইউজার Approve, টিউটোরিয়াল যোগ/এডিট |
| `https://example.com/admin/` | পাসওয়ার্ড বদলানো, staff অ্যাকাউন্ট বানানো |
| `https://example.com/tutorials/` | সাধারণ ইউজাররা যা দেখে |

- লগইন: `/accounts/login/` অথবা `/dashboard/` খুললে লগইন পেজে নিয়ে যাবে।
- লগআউট: উপরের মেনু → **Resources** → **Sign out**।

---

## ২. নতুন ইউজার অনুমোদন

1. `/dashboard/` খুলুন।
2. **Pending approval queue**-তে নতুন নাম দেখবেন।
3. নামের পাশে **Approve** চাপুন। (অথবা **Users** → নাম → **Approve**।)

**মনে রাখুন:** Approve করলেই ওই ইউজার **সব published টিউটোরিয়াল** দেখতে পাবে। প্রতিটা টিউটোরিয়ালের জন্য আলাদা করে Grant দিতে হবে না।

> সার্ভারে যদি ডেভেলপার special “grant mode” চালু করে, তখন আলাদা Grant লাগবে। সাধারণভাবে এটা বন্ধ থাকে।

- **Reject** = ইউজার বন্ধ হয়ে যাবে।
- **Reset to pending** = আবার অপেক্ষার তালিকায় ফিরবে।
- **Toggle all-library access** সাধারণত লাগবে না। এটা শুধু বিশেষ ক্ষেত্রে ব্যবহার করুন।
- নিজের অ্যাকাউন্টে নিজে Approve করা যাবে না।

---

## ৩. নতুন টিউটোরিয়াল যোগ করা

1. `/dashboard/` → **Tutorials** → **+ New tutorial**
2. ঘরগুলো ভরুন:

| ঘর | কী দিবেন |
|---|---|
| **Title** | পরিষ্কার নাম, যেমন “Pump installation — step by step” |
| **Slug** | খালি রাখুন, নিজে তৈরি হবে |
| **Description** | ২–৩ লাইনে কী শেখানো হচ্ছে |
| **Thumbnail** | 16:9 ছবি, JPG/PNG, **৫ MB-এর কম** (1280×720 ভালো) |
| **Category** | আগে থেকে বানানো ক্যাটাগরি বেছে নিন |
| **Duration seconds** | মিনিট × ৬০ (৮ মিনিট = ৪৮০) |
| **Estimated minutes** | ৮ |
| **Video file** | MP4/MOV আপলোড করুন (Bunny চালু থাকলে) |
| **Video provider** | Bunny Stream / YouTube / Plain URL |
| **Video reference** | YouTube হলে লিংক বা ID; Bunny হলে GUID |
| **Published** | ✔ টিক দিন, নাহলে কেউ দেখবে না |
| **Ordering** | ছোট সংখ্যা আগে দেখাবে (10, 20, 30…) |

3. **Save** চাপুন।
4. `/tutorials/` খুলে দেখুন ঠিক আছে কি না।

> **সবচেয়ে সহজ উপায়:** `Video file` দিয়ে MP4 আপলোড করুন। এটি নিজেই provider ও reference ভরে দেয় (যদি Bunny-র key সেট থাকে)।
>
> YouTube ব্যবহার করলে ভিডিওটা **Unlisted** রাখুন, Public নয়।

---

## ৪. টিউটোরিয়াল এডিট / লুকানো / ডিলিট

**Tutorials** তালিকা থেকে:

- **Edit** → লেখা/ছবি/ভিডিও বদলান → Save।
- কাউকে দেখাতে না চাইলে **Edit** → **Published** টিক তুলে দিন → Save। এটা নিরাপদ, পরে আবার Published করা যাবে।
- **Delete** → স্থায়ীভাবে মুছে যায় (progress ও access-ও মুছে যায়)। আগে Unpublish করে দেখুন, তারপর দরকার হলে Delete।

---

## ৫. ক্যাটাগরি

**Categories** → নাম, slug, ordering দিয়ে **Add category**।

- ক্যাটাগরি দিয়ে টিউটোরিয়ালগুলো গ্রুপ করা হয়।
- ক্যাটাগরি Delete করলে টিউটোরিয়ালগুলো থাকে, শুধু ক্যাটাগরি খালি হয়ে যায়।

---

## ৬. কে কী দেখছে

- **Users** → নাম → নিচে **Progress**: কত পার্সেন্ট দেখেছে, শেষ করেছে কি না।
- **Tutorials** → **Access**: কোন টিউটোরিয়ালে কে আলাদা অনুমতি পেয়েছে। (সাধারণত দরকার নেই, কারণ Approve করলেই সব খোলে।)

## ৮. নিরাপত্তা ও নিয়ম

- **admin পাসওয়ার্ড** কারো সাথে শেয়ার করবেন না। অন্য কাউকে কাজ দিতে হলে তার জন্য আলাদা **staff** অ্যাকাউন্ট বানান।
- ইউজারের পাসওয়ার্ড আপনি দেখতে পাবেন না। কেউ ভুলে গেলে `/admin/` → Users → ওই ইউজার → **Change password**।
- টিউটোরিয়ালের ভিডিও YouTube-এ দিলে **Unlisted** রাখুন।
- Thumbnail **৫ MB-এর বেশি** হলে আপলোড হবে না — ছবি ছোট করুন।
- `.env` ফাইল এডিট করবেন না। ওটা ডেভেলপার/হোস্টিংয়ের জন্য।
- **Delete** চাপার আগে নিশ্চিত হোন — ফেরানো যায় না।

## ৯. সমস্যা হলে

| সমস্যা | প্রথমে কী করবেন |
|---|---|
| সাইট খুলছে না | `https://` দিয়ে খুলুন। তারপর cPanel → Setup Python App → **Restart**। |
| লগইন হচ্ছে না | HTTPS ঠিক আছে? পাসওয়ার্ড ঠিক? `/admin/` দিয়ে পাসওয়ার্ড রিসেট। |
| নতুন ইউজার টিউটোরিয়াল দেখছে না | Dashboard → Users → তার status **Approved**? টিউটোরিয়াল **Published**? |
| ভিডিও চলছে না | Tutorial Edit → Published ✔, provider/reference ঠিক? Bunny key সেট? |
| ছবি ভাঙা | Thumbnail আবার আপলোড করুন (৫ MB-এর কম)। |
| CSS/ডিজাইন ভাঙা | হোস্টিং/ডেভেলপারকে বলুন; সাধারণত static file আবার collect করতে হয়। |
| ৫০০ / ৫০৩ error | cPanel → Setup Python App → **Logs**; শেষ ৫–১০ লাইন ডেভেলপারকে পাঠান। |
| `database is locked` | কিছুক্ষণ পরে আবার চেষ্টা করুন। বারবার হলে ডেভেলপারকে MySQL-এর কথা বলুন। |

## ১০. ব্যাকআপ

- **সপ্তাহে একবার:** cPanel → **Backup Wizard** → Home Directory ডাউনলোড করুন।
- **সপ্তাহে একবার:** File Manager → `apps/tmt` → `db.sqlite3` ডাউনলোড করুন (সাইটে কম কাজ চলার সময়)।
- `.env` ফাইলটা আলাদা নিরাপদ জায়গায় রাখুন; কাউকে দেবেন না।
- MySQL ব্যবহার করলে: **phpMyAdmin → Export**।
- Backup Wizard না থাকলে: **File Manager** দিয়ে `public_html` ও `apps/tmt` ফোল্ডার ডাউনলোড করুন।
- ডাউনলোড করা ফাইল নিজের কম্পিউটার/Google Drive-এ রাখুন।
- ভিডিওগুলো Bunny Stream-এ থাকে; সেগুলোর আলাদা backup ডেভেলপার/হোস্টিংয়ের দায়িত্ব।
